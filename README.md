# GitHub 自学笔记

## 一、基础名词
|单词|含义|补充说明|
| ---- | ---- | ---- |
|code|代码|项目源码|
|issues|疑问|提交bug、需求讨论|
|public|公开项目|所有人可见|
|private|私有项目|仅授权人员访问|

### 仓库操作
1. `watch`：关注项目，接收更新通知
2. `fork`：复制一份仓库到自己账号，用于二次开发
3. `star`：点赞收藏项目

## 二、版本分支管理
1. **Branches（分支）**
- `main`：项目默认主分支
- `merge`：合并分支
- `Pull Request / PR`：提交合并申请，把开发分支合并到 `main`

2. **提交规范**
- `fix`：修复bug
- `feat`：新增功能
- `docs`：修改文档

3. **Tag（标签）**：用来标记软件版本

## 三、正式发布 Releases
1. Releases：软件对外发布的正式版本
2. Assets：发布包里的文件
    - `.dmg`：mac系统安装包
    - `.exe`：Windows系统安装包
3. `README`：项目说明文档（中文/外文）
4. `License`：开源许可证（7种）
    - 宽松型许可证
    - 著作权型许可证

## 四、4种下载/使用方式
1. Release：直接下载成品安装包，开箱即用
2. Download ZIP：打包下载完整源代码
3. `git clone`：复制仓库地址，克隆完整代码到本地
4. Fork：复刻仓库到自己账号，参与开源二次开发
